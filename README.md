## 🚀 Key System Capabilities

### 1. Multi-Page Fluid Architecture
Divided into 5 dedicated views with URL hash routing (`#dashboard`, `#curriculum`, `#planner`, `#analytics`, `#notes`):
* 🏠 **Dashboard (`#dashboard`)**: Global performance indicators, course cards overview, active study stopwatch, and quick time logging.
* 📚 **Curriculum Explorer (`#curriculum`)**: Course switcher dropdown, granular module accordions, video timestamps, and topic checklists.
* 🎯 **Finish Estimator ("Kitna Time Lagega") (`#planner`)**: Dynamic pace slider (0.5h to 8.0h/day) with course-by-course finish date projections table.
* 📅 **Daily Study Logs & Streaks (`#analytics`)**: Daily study session history table and consecutive day study streak monitor (`🔥 N-Day Streak`).
* 📝 **Revision Notes Vault (`#notes`)**: Searchable archive of all notes, Google Colab notebooks, and code links saved across lectures.

### 2. Micro-Animations & Design
* Page glide transitions (`fadeSlideIn`)
* Checkbox bounce pop celebrations (`checkPop`)
* Pulsing live beacon indicators (`pulseDot` & `pulseGlow`)
* Glassmorphism elevation card hover effects
* Dynamic gradient progress bars with ease-in-out animations

### 3. Complete Data Privacy & Persistence
* 100% client-side `localStorage` auto-saving — zero server login required.
* One-click JSON backup export and restore to sync progress between smartphone and PC.

bash start.sh 5000

Open [http://localhost:5000](http://localhost:5000) on your device.

## 🚢 Enabling GitHub Pages (Free Worldwide Hosting)

1. Open your repository on GitHub: `https://github.com/30Piyush2025/MY_STUDY_PROJECT`
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
4. Set Branch to **`main`** and Folder to **`/(root)`**, then click **Save**.
5. Your tracker will be live in 1–2 minutes at:
   **`https://30piyush2025.github.io/MY_STUDY_PROJECT/`**
